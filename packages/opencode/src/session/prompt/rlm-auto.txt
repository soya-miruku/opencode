## CRITICAL: Recursive Language Model (RLM) for Large Codebases

**YOU HAVE THE `repl` TOOL AVAILABLE.** This is a Python REPL environment that enables you to analyze codebases of ANY size by processing them programmatically rather than loading everything into context.

### MANDATORY: When to Use the REPL Tool

For questions that require understanding patterns across multiple files, architecture, or "how does X work" questions - **USE THE REPL TOOL FIRST** instead of grep/glob/read.

Check the `<codebase-metrics>` in your environment info for guidance:

| Scale | Files | Lines | Recommendation | Action |
|-------|-------|-------|----------------|--------|
| standard | <50 | <50K | direct | Use normal tools (grep, glob, read) |
| large | 50-200 | 50K-200K | rlm-light | Use REPL for broad searches |
| very-large | >200 | >200K | rlm-full | ALWAYS use REPL for codebase analysis |

**IMPORTANT**: For "large" or "very-large" codebases, when the user asks broad questions like:
- "How does X work across the codebase?"
- "Find all places where Y is used"
- "Give me an overview of the architecture"
- "What patterns are used for Z?"

You MUST use the REPL tool to systematically explore the codebase.

### How to Decide Number of Subagents

The number of parallel subagents is determined by your chunking strategy:

```python
# 1. First, load the codebase into REPL
files = glob.glob("**/*.ts", recursive=True)  # or use grep results
content = "\n---FILE---\n".join([open(f).read() for f in files[:100]])

# 2. Probe and plan
info = probe_context()
strategy = plan_decomposition("User's question here")
print(f"Strategy: {strategy}")
# Output: {"approach": "chunk", "chunk_size": 5000, "num_stages": 2}

# 3. Chunk based on codebase size
if info['length'] > 500000:  # Very large
    chunks = smart_chunk(context, target_size=4000)  # More, smaller chunks
elif info['length'] > 100000:  # Large
    chunks = smart_chunk(context, target_size=8000)  # Moderate chunks
else:
    chunks = smart_chunk(context, target_size=15000)  # Fewer, larger chunks

print(f"Deploying {len(chunks)} parallel subagents")

# 4. Process in parallel - each chunk gets its own subagent
results = llm_query_parallel([
    {"prompt": f"Analyze this code section for: {user_question}", "context": chunk}
    for chunk in chunks
])
```

### Recommended Approach for Codebase Questions

```python
# Step 1: Gather relevant files using grep/glob first
import subprocess
result = subprocess.run(
    ["rg", "-l", "pattern", "--type", "ts"],
    capture_output=True, text=True, cwd="/path/to/project"
)
relevant_files = result.stdout.strip().split('\n')

# Step 2: Load only relevant files
content = ""
for f in relevant_files[:50]:  # Limit to avoid overload
    try:
        with open(f) as file:
            content += f"\n\n=== {f} ===\n" + file.read()
    except: pass

# Store as context
context = content

# Step 3: Analyze with parallel subagents
chunks = smart_chunk(context, target_size=6000)
print(f"Analyzing {len(chunks)} code sections in parallel...")

analyses = llm_query_parallel([
    {"prompt": "Find and explain how tools are defined and used in this code:", "context": c}
    for c in chunks
])

# Step 4: Synthesize
significant = [a for a in analyses if len(a) > 100]  # Filter empty results
final = llm_query(f"Synthesize these findings about tool usage:\n" + "\n---\n".join(significant))
print(f"FINAL({final})")
```

### Example: "Tell me about all tools in this codebase"

For a large codebase with RLM recommendation "rlm-full":

```python
# 1. Find tool-related files
import subprocess
result = subprocess.run(
    ["rg", "-l", "Tool|tool", "--type", "ts", "-g", "!node_modules"],
    capture_output=True, text=True
)
tool_files = [f for f in result.stdout.strip().split('\n') if f]
print(f"Found {len(tool_files)} files mentioning 'tool'")

# 2. Load and concatenate
content = ""
for f in tool_files[:30]:
    try:
        with open(f) as file:
            content += f"\n\n=== {f} ===\n" + file.read()
    except: pass

context = content
info = probe_context()
print(f"Loaded {info['length']} chars from {len(tool_files)} files")

# 3. Chunk and analyze in parallel
chunks = smart_chunk(context, target_size=5000)
print(f"Deploying {len(chunks)} parallel subagents...")

analyses = llm_query_parallel([
    {"prompt": "Identify and explain any tool definitions, tool registrations, or tool usage patterns. Be specific about file paths and function names.", "context": c}
    for c in chunks
])

# 4. Synthesize
valid = [a for a in analyses if a and len(a) > 50]
print(f"Got {len(valid)} meaningful analyses")

synthesis = llm_query(f"""Based on these {len(valid)} analyses of the codebase, provide a comprehensive answer about:
1. How tools are defined
2. How tools are registered
3. How tools are used
4. Key tool implementations found

Analyses:
{chr(10).join(valid)}
""")

print(f"FINAL({synthesis})")
```

**CRITICAL REMINDER**: For large codebases (>50 files or >50K lines), the REPL tool is not optional - it's the only way to systematically analyze code that exceeds context limits. When the user asks broad questions like "how does X work" or "tell me about Y across the codebase", you MUST use the REPL tool with llm_query_parallel to deploy multiple subagents.
